# Airburst — architecture notes

Design notes for `games/airburst/`, loaded when Claude Code works in this directory. The root [CLAUDE.md](../../CLAUDE.md) keeps the rules that break things; this file has the reasoning and the model. Past decisions are in [docs/DECISIONS.md](../../docs/DECISIONS.md) (2026-10-14 for this game's design).

The classics cabinet's Missile Command. Warheads fall on six cities; three batteries answer with interceptors that burst where the player taps.

- **[engine.js](engine.js)** — pure logic, seeded LCG only (`rand`, the same one Flak Battery and Feedline use).
  - **The seam is Hull Breach's**: `step(w, dt)` reads no input, and the shell calls `fire(w, x, y)` on a tap, as Hull Breach's calls `launch`. `fire` picks the battery (`baseFor`: nearest standing one with ammunition), so the player aims and the game picks the gun.
  - **One board, portrait** (600×1100). `GROUND_Y` is the surface; `FIRE_FLOOR` (40px above it) is the lowest point an interceptor may be aimed, since a burst on the ground only hits what it protects.
  - Warheads are straight lines from a point above the board to a target on the ground (a city or a battery), positioned by distance travelled `d` along `len`. A warhead touching any burst's *current* radius is destroyed (`blastRadius(t)`: grow, hold, fade). Destroyed warheads do not themselves burst — no chain reactions.
  - **Splitting** starts at `SPLIT_WAVE` (4): a warhead may carry a `splitAt` height and becomes `splitInto(wave)` warheads there, each aimed at its own target. **The split roll and the split height are two LCG advances taken for every warhead released, whether or not it splits**, so a seeded run releases warheads from the same positions on any wave. A test pins that; keep it if the split logic changes.
  - A battery hit by a warhead loses its remaining ammunition until the next wave; **batteries are rebuilt every wave, cities are not**. A lost city comes back at the end of a wave for every `BONUS_CITY_EVERY` points crossed. Losing the last city ends the run immediately.
  - A wave ends when everything has been released and nothing is left in the air (`endWave`): spare ammunition and standing cities pay, times `scoreMult(wave)`, and `w.lastBonus` holds the breakdown for the banner. `nextWave` advances; the shell sits a banner between waves, which is also where the run is saved.
  - **Difficulty curve:** `waveCount`, `warheadSpeed` and `spawnGap` per wave, all capped. The full-run test's bot, which leads each warhead by the interceptor's real flight time and does not fire twice at one target, holds about 8-9 waves; the test pins 5, the wave that will open the next classic (Shield Wall). A bot that aimed a fixed 0.45s ahead lost on wave 2 — leading properly is the skill the game teaches.
  - `snapshot`/`hydrate` keep everything, including objects in flight and the seed, so a resumed run releases the warheads it would have.
- **[airburst.html](airburst.html)** — the shell. Fires on `pointerdown` on the canvas (a gameplay surface; `shared/tap.js` leaves it alone). Banners are raised on false→true *edges* of `waveClear`/`over` in the frame loop. Records **waves held** (`wavesCleared`) to `shared/unlocks.js` on each wave clear, for the classics chain. Saves on a held wave and on page hide, with Hull Breach's v45 rule (a page where nothing has started leaves a stored run alone). A run saved behind the wave banner resumes into the next wave.
- **Art:** warheads are cubes (invaders, the absolute rule) at the head of a fading trail; cities, batteries and bursts are round. Bursts are the accent colour (`#7fd0e6`/`#a8e4f2`), which is also the shell's `--accent`.
- **Tests:** [engine.test.js](engine.test.js) (board → determinism → firing → warheads → splitting → waves → saving → full run), [render-test.mjs](render-test.mjs) and [resume-test.mjs](resume-test.mjs).
- **Unlock:** the cabinet opens Airburst at Hull Breach level 3 cleared (`GATES` in `shared/unlocks.js`). Hull Breach records levels cleared, and seeds that record from its level-select history so a pre-v53 player is not made to repeat them.
